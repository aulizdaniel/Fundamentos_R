## Qué hay en este repositorio

| Archivo | Para qué sirve |
|:--|:--|
| `index.html` | El documento de consulta ya renderizado (es la página que se publica) |
| `introduccion_01.R` | El script del taller: se sigue en vivo y se editan los ejercicios |
| `01_Fundamentos_R.qmd` | El código fuente del documento (Quarto) |
| `estilos.css`, `referencias.bib` | Estilos y bibliografía del documento |

## Cómo usarlo

1. Abre la página de consulta (liga de arriba) para ver la explicación y los resultados.
2. Descarga `introduccion_01.R` (en GitHub: abrir el archivo y usar el botón *Download raw file*) y ábrelo en RStudio.
3. Corre el código línea por línea con `Ctrl + Enter` y resuelve los ejercicios en los espacios en blanco.

**Requisitos:** R, RStudio y los paquetes `tidyverse`, `readxl` y `lubridate`.

## Cómo volver a generar el documento

Abre `01_Fundamentos_R.qmd` en RStudio y haz clic en **Render**. Necesitas Quarto (viene incluido en las versiones recientes de RStudio) y los paquetes `tidyverse`, `readxl` y `lubridate`. El resultado se guarda como `index.html`.
